Finding Detail
F1 Critical · CVSS 9.1
Military Theater Posture Exposed
Affected Component
Authorization layer — Military Intelligence API
Endpoint
/api/military/v1/get-theater-posture
Description
Real-time military posture for 9 global theaters — Iran, Taiwan, South China Sea, Black Sea, Korea, Baltic, East Med, Israel-Gaza, Yemen — returned with zero authentication.
Steps to Reproduce
  1. Open any browser with no account or login
  2. Navigate directly to the endpoint URL
  3. Full military theater data returned immediately
Business Impact
Nation-states spend billions gathering this intelligence. Freely accessible to any actor worldwide including adversarial states — a direct national security risk.
Remediation
Enforce authentication middleware on all /api/military/* routes at the API gateway level. Require valid X-WorldMonitor-Key header.
