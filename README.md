# SIH26163 — Security Assessment of World Monitor Application

## Problem Statement
Security assessment of the World Monitor web/mobile platform to identify 
vulnerabilities that could compromise confidentiality, integrity, or 
availability of the system.

## Organization
National Technical Research Organisation (NTRO)

## Our Approach
We will conduct a comprehensive security assessment covering:
- Authentication and session management
- Authorization and access control
- Input validation and data handling
- API security
- Client-side security controls
- Secure communication mechanisms

## Tools & Technologies
- Burp Suite (intercepting proxy)
- OWASP Top 10 methodology
- Postman (API testing)
- Python (automated scanning scripts)
- Manual source code review

## Target Application
- Live App: https://www.worldmonitor.app
- Source Code: https://github.com/koala73/worldmonitor
